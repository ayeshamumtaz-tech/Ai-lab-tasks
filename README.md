# Lab 4: Informed Search — Heuristics & A*

## Files
- `lab4_astar.py`: Python code for A*, UCS, and the overestimate experiment.
- `outputs.txt`: output captured by running the code.
- `Lab4_Report.docx`: report with calculations, heuristic audit, comparisons, and conclusion.

## How to run
1. Keep `lab4_astar.py` in your lab folder.
2. Open a terminal in that folder.
3. Run: `python lab4_astar.py`

The code uses a list as a priority queue, with `sort()` and `pop(0)`, similar to the simple UCS approach shown in class.
